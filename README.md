# ⭐ مغامرة النجمة (الموقع)

لعبة منصّات مجانية بالعربية. هذا المستودع **عام (Public)** واسمه `USERNAME.github.io`.

كل ما تدفعه (push) إلى الفرع `main` ينشره تلقائيًا `.github/workflows/deploy-site.yml` على فرع `gh-pages`،
ويستبدل `__SITE__` برابط موقعك تلقائيًا. من **Settings ← Pages** اجعل المصدر: فرع `gh-pages` والمجلد `/ (root)`.

لا ترفع هنا أي مفاتيح توقيع (`.gitignore` يمنعها). تطبيق أندرويد يُبنى في مستودع **خاص** منفصل.
